# 设置与用户管理

## 个人偏好

登录后打开“设置 → 通用”，可调整自己的偏好：

| 设置 | 默认行为 |
| --- | --- |
| 导入前人工确认 | 开启后先校对再保存，适合需要逐题核对的场景 |
| 录入题目的年级识别规则 | 默认固定模式，使用所选年级学期；未指定时沿用账户当前年级，也可切换为 AI 识别 |
| SVG 动画讲解 | 默认开启 |
| GeoGebra 动态演示 | 默认关闭 |
| 题目判重相似度阈值 | 默认 90%，相似度严格大于阈值时判重 |
| 已掌握阈值 | 默认 50%，掌握概率达到阈值的错题视为已掌握 |

界面主题不在设置中，而是通过顶部导航栏的主题按钮切换：自动（跟随系统，默认）、浅色或深色，同样按用户保存，换设备登录后保持一致。

个人偏好按用户保存。AI 服务配置和应用时区属于全局设置，需要管理员权限。

## 录入题目的年级识别规则

在「设置 → 通用」选择规则后点击「保存年级规则」，普通用户和管理员均可修改自己的规则。

- **固定年级**：新题使用所选年级学期；未指定时，按账户的学段、入学年份和应用时区推算当前年级。明确指定的固定值不会随学年变化。
- **AI 识别**：根据题目内容、知识点和教材进度判断，识别时不注入学生当前年级；无法确定时保持未设置。
- 规则适用于图片识别、文字解题、框选批量、直接录入和 Openclaw 批量上传。手工填写或在校对页修改的年级优先。
- 图片和文字解题会在原有 AI 请求中返回年级；直接录入或外部识别结果缺少年级时，补充一次短请求并计入每日 AI 用量。重复题不再识别年级，已识别但无法确定的结果不会反复请求。
- 只影响新录入的题目；修改规则不会批量改动已有题目，恢复备份时保留题目原年级。规则及固定值会随本人的 JSON 备份保存和恢复。

## 应用时区

应用默认使用北京时间 `Asia/Shanghai`。管理员在“设置 → 通用 → 应用时区”输入有效的 IANA 时区名称并保存，例如 `UTC`、`Europe/London` 或 `America/New_York`。

时区保存在 `config/app-config.json` 的 `timeZone` 字段。旧配置没有此字段时，自动回退到 `Asia/Shanghai`；普通用户可查看当前全局时区。

以下功能使用应用时区：

- 题目、练习历史、试卷和管理页面中的日期显示。
- 试卷默认标题中的时间、导出文件名和考试日期录入。
- 按日、按月统计，以及年级学期计算。

数据库与 API 中带 `Z` 的 ISO 时间仍表示同一个绝对时刻，显示时再转换。保存后当前页面使用新时区，其他已打开的页面刷新后生效；已保存的试卷标题文字不会自动改写。

详细规则见[时区说明](https://github.com/margrop/wrong-notebook/blob/main/doc/TIME_ZONE.md)。

## AI 数据授权

使用 AI 功能会把任务所需的题目文字、图片、作答、答案与解析等发送给管理员配置的第三方 AI 服务商。每个账号（包括管理员）首次登录后会看到「AI 数据授权」弹窗，列出发送的数据、当前服务商和[隐私政策](https://wrong-notebook.margrop.net/privacy/)，同意后才能使用 AI 功能：

- 选择「暂不同意」后，本次浏览不再主动弹出；之后点击任何 AI 功能时会再次弹出，同意后重新操作一次即可。
- 未同意时服务端直接拒绝 AI 请求（错误码 `AI_CONSENT_REQUIRED`），不会向服务商发送数据；掌握程度改按规则估算，其他功能照常使用。
- 在「设置 → 账户 → AI 数据授权」中可查看同意时间、同意或撤回。撤回不影响已发送给服务商的数据。
- 授权跟随账号保存，不随备份导出或导入。升级到该版本前的账号也需要同意一次；只用 [Openclaw](Openclaw-Integration) 调用的账号，需先在网页登录同意。

## 权限与用户管理

| 角色 | 主要权限 |
| --- | --- |
| 普通用户 | 管理自己的错题、练习、试卷和个人偏好，导入导出本人数据 |
| 管理员 | 使用全局 AI 和提示词设置、时区设置、注册开关、用户管理及管理范围的数据导入导出 |

管理员从“设置 → 用户管理”进入后台，可查看使用统计，启用、禁用或删除用户。删除前应确认对象并[备份数据](Backup-and-Restore)。

普通用户可在“设置 → 危险 → 注销账号”中输入当前密码，永久删除自己的账号及名下全部数据（错题、错题本、标签、练习记录、试卷等），完成后自动退出登录，无法恢复，需要保留的数据请先导出。管理员账号不能自助注销，避免实例失去管理员；需要清空数据时使用同一页的系统初始化。

新用户注册默认关闭，避免服务暴露到公网时被陌生人注册并消耗 AI 额度。需要为家人创建账号时，管理员在“设置 → 用户管理”中打开“允许新用户注册”，账号注册完成后再关闭；也可以用环境变量 `ALLOW_REGISTRATION=true` 改变默认值，网页中保存过的开关优先。升级前已在网页中保存过设置的实例，保持原来的注册开关。注册关闭时，登录页不显示“立即注册”，改为提示联系管理员开启注册。

### 每日 AI 次数

为避免孩子反复生成讲解、重新出题而耗尽 API 额度，管理员可在“设置 → 用户管理”中设置“每人每日 AI 次数”，用户列表同时显示每人今天已用的次数和消耗的 token（输入 / 输出）。

- 计入次数的是用户主动发起的 AI 操作：识别题目、重新解答、举一反三出题和判题、配图、修复公式、GeoGebra、动画讲解（含补写语音讲解稿）、重新标注知识点和组卷。一次操作计 1 次，整套试卷和整本错题本重新标注也各计 1 次；写法一致直接判对的答案不调用 AI，不计次数；云端语音合成消耗语音服务商额度，也不计次数。
- 后台自动进行的掌握概率评估不计入次数，但它消耗的 token 计入当天的 token 用量。
- token 用量取自 AI 服务商返回的统计，每次请求单独记录（含失败的请求）；服务商未返回用量时不计 token。
- 0 表示不限制（默认）；管理员不受限制。也可以用环境变量 `AI_DAILY_LIMIT` 设置默认值，网页中保存的值优先。
- 次数按应用时区每天零点重置。用完后再点 AI 功能会提示“今天的 AI 使用次数已达上限”。

### 同一模型 AI 并发上限

多人同时识别题目、生成讲解时，短时间内的大量请求容易被服务商以 429 限流拒绝。管理员可在“设置 → 用户管理”中设置“同一模型 AI 并发上限”：

- 同一渠道、接口地址和模型同时进行的 AI 调用不超过上限，超出的调用按先后顺序排队，前面的完成后自动开始；切换到其他模型时各自计数。
- 取值 1～100，默认 5。服务商限流较严（如免费额度、试用套餐）时可调低；排队时间过长且没有 429 报错时可调高。
- 保存后对之后的调用立即生效。也可以用环境变量 `AI_CONCURRENCY_LIMIT` 设置默认值，网页中保存的值优先。
- 排队时间计入页面上的 AI 超时，等待过久的任务可能在页面上显示超时。

全新安装通过一次性初始化链接创建第一个管理员（见[常见问题](FAQ)），不再预置固定密码的默认管理员。已有实例升级保留原账户；`scripts/seed-admin.js` 只为已有的 `admin@localhost` 恢复管理员角色，不会创建账号。

## 后台任务与进度

页面右下角的任务入口展示识别、动画、讲解稿、动画语音（云端语音）、重新解答、批量标注、数据导入和组卷等耗时操作的状态。部分批量任务提供已处理数量和失败数量。

录入界面的百分比是按压缩、上传、分析、处理、保存阶段给出的估计，不能理解为 AI 已完成的真实比例；已用时间用于了解等待时长。

任务列表保存在当前服务进程内存中。页面跳转通常不会停止已经开始的服务端处理，但服务重启会清空列表，运行中的任务也不能据此自动恢复。完成的业务数据以数据库中的保存结果为准。

## 查看运行版本

设置中的“关于”和 `GET /api/health` 可查看运行版本。排查问题时记录版本、复现步骤及脱敏后的错误提示；不要发送实际 API Key 或完整配置文件。

## 人教版课标知识点

管理员可以导入「人教版课标体系」，作为与内置知识点并存的另一套标签：

1. 下载所需的 JSON 文件：[topics.json](https://raw.githubusercontent.com/xiaoyang111222/cn-math-taxonomy/HEAD/data/topics.json)（约 2.6MB，来自 [cn-math-taxonomy](https://github.com/xiaoyang111222/cn-math-taxonomy)）。
2. 打开“设置 → 用户管理 → 人教版课标知识点”，点击“选择 topics.json 并导入”。

数据以数学为主，也包含语文、英语、物理、历史、地理和道德与法治（归入政治）；小学科学等不支持的学科会跳过。导入是增量的，可重复执行，不改动内置标签体系和已有题目。导入后创建错题本时可在“标签体系”中选择「人教版课标体系」，创建后不可更改。也可在命令行执行 `npx tsx scripts/seed-cnm-tags.ts <文件路径>`。

## 隐私与遥测

使用协议只针对管理员：全新安装时，创建管理员的人须在初始化页（飞牛OS 为安装向导）勾选同意[使用协议](https://github.com/margrop/wrong-notebook/blob/main/doc/EULA.md)，实例随后默认开启匿名遥测外发。普通用户的注册、登录和使用不涉及协议。

“设置 → 用户管理 → 隐私与遥测”中可以：

- **外发到收集服务**：约每 6 小时发送一批匿名的功能使用统计和错误指纹，不含用户或实例标识、题目内容、AI 对话或错误原文。从旧版本升级的实例默认关闭，管理员登录后会看到提示横幅；开启前需要在对话框中勾选同意使用协议。
- **本地记录**（默认关闭）：功能统计与脱敏后的错误详情只保存在本机数据库，供排查问题，按保留天数（1–365，默认 30）自动删除。
- **错误回报**：只在外发或本地记录开启时生效。
- **收集服务地址**：默认官方地址，可改为[自建的收集服务](https://github.com/margrop/wrong-notebook-telemetry)（只允许 https，局域网地址可以用 http）。
- 查看待发数量、上次外发时间，以及“本实例收集了什么”（最近 20 条事件和错误），可立即清空。

设置环境变量 `TELEMETRY_DISABLED=true` 时强制关闭全部遥测，面板只读。协议升级后，管理员登录时会看到无法关闭的协议更新对话框，同意前暂停外发、管理写操作不可用；普通用户不受影响。遥测数据不进入数据备份。详见[隐私说明](https://github.com/margrop/wrong-notebook/blob/main/doc/PRIVACY.md)。

## 调试日志

遇到难以描述的问题时，管理员可以导出调试日志发给作者：

1. 打开“设置 → 用户管理”，打开“调试日志”中的“调试模式”开关（开启时会清空上一轮记录）。
2. 复现问题，面板中会显示已记录的条数。
3. 点击“导出调试日志”，得到 `wrong-notebook-debug-<时间>.json`，随 Issue 一并发送；之后可关闭开关。

调试模式下会记录全部服务端日志（包括 `LOG_LEVEL` 未输出的 debug、trace 级别，如 AI 请求与响应）和所有用户在浏览器中的未捕获错误；导出文件还包含运行版本、系统环境和脱敏后的配置。

- API Key、密码、令牌、Cookie 等字段导出时替换为 `[REDACTED]`，图片只保留类型和长度；日志中仍可能有题目内容和用户名，发送前可自行检查。
- 日志只保存在服务进程内存中，最多保留 5000 条（超出时丢弃最早的记录）；开启 24 小时后自动关闭，服务重启后清空。
