# 错题管理指南

## 创建错题本

创建错题本时选择学段（小学、初中或高中）和学科。学段与学科决定 AI 使用的知识点库，创建后不可修改，建议按学习阶段和学科分别管理。

## 录入题目

| 入口 | 适用情况 |
| --- | --- |
| 图片上传、拖拽、拍照 | 纸质试卷、练习册和已有题目图片 |
| 剪贴板粘贴 | 已复制的截图或图片，使用 `Ctrl/⌘+V` |
| 屏幕截图 | 浏览器支持屏幕共享，且页面满足安全上下文要求 |
| 手动输入 | 已有文字题干，可使用 Markdown 与 LaTeX |
| 直接录入 | 手工整理已知的题干、答案和解析 |

图片可以先裁剪；一张图片上有多道题时，可框选多题批量导入。尽量保留完整题干、必要图形和学生作答，避免模糊或裁掉条件。

在“设置 → 通用”开启“导入前人工确认”后，可先在校对页修改识别内容再保存。AI 可能识别错数字、符号和图形关系，保存前应核对原题。

## 自动判重

导入时会与当前用户的已有题目比较题干，跨错题本参与判重。默认阈值为 90%，可在个人通用设置中调整。

- 相似度**严格大于**阈值时，返回已有题目，并在原题下记录一次做错。
- 相似度等于阈值时，不按超过阈值处理。
- 相似度是规范化题干后的字符编辑相似度，不代表数学含义相同。
- 重复导入记录参与后续掌握情况评估；需要核对时可查看原题的作答历史。

错题本还提供两题相似度比较，便于判断阈值是否适合自己的题目。数字或条件只改动少量字符时，相似度仍可能较高，应结合题意判断。

## 题目详情

每道题集中展示题干、答案、解析、知识点、难度、学期和卷别，并可查看拍照原图。

| 信息或操作 | 说明 |
| --- | --- |
| 6 位题目 ID | 可复制，在错题本按 ID 定位；打印中显示为来源 ID |
| 1～5 星难度 | AI 参考竞赛数学难度标准评定，可手动修改 |
| A/B 卷 | 未指定时，1～3 星默认 A 卷，4～5 星默认 B 卷；已有手动选择优先 |
| 知识点 | 使用对应学段与学科的标签，支持单题或整本重新识别 |
| 重新生成完整解答 | 生成新的答案和解析，覆盖前会要求确认 |
| 修复 LaTeX | 检测到公式语法问题时出现，供 AI 修正公式写法 |
| 原题图片 | 可查看、替换或补充，用于核对识别结果 |

未评级的题目不会仅凭默认规则自动指定卷别。重新生成完整解答保留知识点和错因信息。

## 配图和动态讲解

- **SVG 配图**：由 AI 根据题目生成静态 SVG，供详情、练习和打印使用；原图可单独查看。
- **SVG 动画讲解**：按解题思路分步骤演示，支持暂停、拖动进度、重播和全屏，个人设置默认开启。点击播放器上的喇叭开启语音讲解（默认关闭，开启后会记住），用浏览器的语音合成朗读每一步，画面等语音读完再进入下一步，语速可在 0.75×～1.5× 间切换。旧动画没有讲解稿时朗读画面底部的字幕；点击动画上方的「补充讲解稿」可由 AI 按现有画面补写讲解稿，画面不变，不需要重新生成动画（计 1 次 AI 动画讲解用量）。已有讲解稿时按钮显示为「重写讲解稿」。动画文字跟随界面语言，中英文版本分别生成和保存，切换语言时自动显示对应版本。
- **GeoGebra 动态演示**：供数学、物理题生成交互图形，个人设置默认关闭。

已生成的动画和 GeoGebra 演示可在确认后删除。生成的图形和解答需要人工核对，尤其是几何位置、计数过程和结论。

## 筛选与批量操作

可按掌握状态、知识点、时间、年级学期和卷别等筛选，再进行批量操作或打印。删除前确认筛选条件和选中范围；需要长期保存时先[备份数据](Backup-and-Restore)。

## Markdown 与公式

题目、答案和解析支持 Markdown，公式由 KaTeX 渲染：

```text
行内公式：$a^2+b^2=c^2$ 或 \(a^2+b^2=c^2\)
独立公式：$$\frac{a}{b}$$ 或 \[\frac{a}{b}\]
```

编辑时可在源代码与预览间切换。复杂表格和公式的写法见 [Markdown 指南](https://github.com/margrop/wrong-notebook/blob/main/doc/MARKDOWN_GUIDE.md)与[表格识别说明](https://github.com/margrop/wrong-notebook/blob/main/doc/TABLE_RECOGNITION.md)。
