# 练习与组卷

## 举一反三

从错题详情进入举一反三，选择难度，由 AI 生成考查相同知识点的变式题。生成题型限定为填空题或解答题，题目内容不应携带题号、分值或选择题选项。

先独立作答，再查看答案与解析，并记录做对或做错。记录会关联原题，用于回看练习历史和评估掌握情况。

提交答案后自动判题：与标准答案写法一致（忽略空格、公式符号和"答案是"等前缀，选择题只比较选项字母）时直接判对；否则由 AI 对照标准答案和解析判定，并给出一句判定依据。等价写法（如 `1/2` 与 `0.5`）算对，多个答案只答出一部分算错。AI 判定失败时由用户自己选择结果。判定只是建议，保存前可以修改。

每道错题会暂存最近一次生成的变式题与解答。再次进入举一反三时直接显示这道题和生成时间，不再重新调用 AI；需要新题时点「重新生成」，新题会替换暂存内容。

## 掌握情况

掌握概率依据原题关联的实际作答历史评估，来源包括举一反三、试卷作答和重复导入。

- 优先使用 AI 评估；AI 调用失败时使用规则估算，并记录评估来源。
- 错题的状态由作答记录和掌握概率自动决定，不再手动标记：
  - **待复习**：还没有举一反三记录。
  - **复习中**：有记录，掌握概率低于已掌握阈值（新记录尚未评估完成时也归为复习中）。
  - **已掌握**：有记录，掌握概率达到已掌握阈值。
- 已掌握阈值默认 50%，每个用户可在“设置 → 通用”中单独调整（1%～100% 的整数）；修改后状态筛选、统计和随机试卷的掌握范围立即按新阈值计算。
- 错题本可按这三种状态筛选；随机试卷的“未掌握”范围包括待复习和复习中。
- 没有可用作答记录时，掌握概率为空。
- 评估在后台执行，回填结果后可能需要稍等或刷新才能看到更新。

掌握概率用于辅助安排复习。它不保证学生已经理解题目，也不等同于考试得分。

## 今日复习

导航栏的「复习」页列出今天需要复习的错题，首页也会显示今日待复习的数量。

- 复习按 1、2、4、7、15、30 天的间隔安排：录入后第二天第一次复习；之后每次做对进入下一轮间隔，做错回到第一轮。
- 间隔从最近一次作答的日期算起，作答记录来自举一反三、手动录入、试卷和重复导入；“没做”的记录不影响计划。
- 连续做对 6 次后不再安排复习。日期按应用时区计算，最早到期的题排在前面。
- 点卡片进入详情，或点「举一反三」直接练习；录入结果后，这道题会按新的间隔离开列表。

## 生成错题试卷

1. 打开试卷入口，选择错题本、知识点、掌握情况等范围，以及模式（举一反三 / 原题直出）。
2. 系统从范围内抽取错题（默认"优先练习较少"：举一反三记录越少的题目越优先，练习次数相同时优先抽取从未出现在已有试卷中的题目，仍相同时随机；也可选"完全随机"）。
3. **举一反三**（默认）：由 AI 生成对应的变式题，在后台任务中查看生成状态，完成后打开试卷检查题干、图形和答案。可指定难度（简单/中等/困难/挑战）。
4. **原题直出**：直接使用原题的题干、答案、解析和配图组卷，不调用 AI、不消耗 AI 额度，创建后立即可打印。无需选择难度。
5. 打印或导出，完成后按题回填作答结果。

原题直出模式的试卷不显示"换一道题"按钮（原题不可更换），但仍可"重新生成解答"；录入结果时难度记为空。

试卷列表的状态依次为生成中、已生成（或部分失败、生成失败），录入过作答结果后显示为已完成。

试卷保留来源题目 ID，可据此回到原题。作答结果支持做对、做错和未作答；同一题可以保留多次结果，关联到原题的复习历史。

## 打印与导出

| 方式 | 内容与选项 |
| --- | --- |
| 错题打印 | 对筛选结果打印，可选题目文字或原图、答案、解析、知识点及图片比例；不显示答案和解析时支持选择全局留白档位（按题型自动、不留白、小、中、大），并可在每道题下方通过滑块或 `-`/`+` 按钮单独手动微调留白高度（0～600 px），调整后自动保存到该题，下次打印直接沿用，点“恢复默认”或“重置单题留白”可改回按全局档位。题目较多时选题列表默认收起，可按题目文字、编号或知识点搜索，全选、清空、反选作用于搜索结果；预览中每题右上角的“不打印此题”可直接移除；显示选项记在本机浏览器中，下次打开沿用。原图按需加载，点击打印时先加载完全部图片再打开打印对话框 |
| 试卷打印 | 提供打印预览，可选择是否包含答案页，以及每题下方的留白：按题型自动（判断、选择、填空题约 0.3–0.4 cm，解答题约 6.3 cm，每多一个小问加约 3.2 cm，最多约 14.8 cm），或固定为不留白、小（约 1.6 cm）、中（约 3.2 cm）、大（约 6.3 cm），同时支持按题单独手动调节留白高度（0～600 px），调整结果保存在试卷中，下次打开直接沿用；全局模式选择会记在本机浏览器中。存在配图的试卷可按题逐个调整或全卷统一调整配图比例（10%～200%）与显示位置（居左/居中/居右，默认居中），保存后用于显示、打印与导出 |
| 下载 HTML | 保存试卷 HTML，再用浏览器打开 |
| 保存 PDF | 在浏览器打印对话框中选择“保存为 PDF” |

打印前检查分页、公式和配图是否完整；纸张、缩放和页边距由浏览器打印设置控制。

## 学习统计

错题统计展示累计错题、已掌握数量、掌握率、学科分布和趋势图；练习统计单独展示练习次数、正确率、活跃天数，以及难度与学科分布。两个页签都支持按时间范围（近 7 天 / 近 30 天 / 近 6 个月 / 全部）和学科筛选。筛选某个学科后，点击待复习 / 复习中 / 已掌握卡片可直接跳转到该错题本中对应状态的错题列表（地址栏带 `?mastery=` 参数，错题列表按此参数预设筛选）。趋势图按粒度显示每日或月度，包含「新增」与「新掌握」两个系列：新增是每桶内创建的错题数，新掌握是最近一次掌握评估时间落在该桶内的已掌握错题数（近似口径，以最近一次评估时间作为掌握时间；这类错题可能创建于范围之前，因此不受创建时间范围限制）。对比两个系列可以直观看出错题本是在变少还是越积越多。错题统计页签在科目分布与趋势图下方还有「错因分布」卡片：上半部分按作答状态（不会做 / 做错了 / 未判断）展示环形图与占比，下半部分按错误类型展示横向条形列表（名称 + 数量 + 进度条），错误类型为自由文本，仅显示数量前 7 个，其余合并为「其他」；尚未填写错误类型时显示提示文案。统计同样受当前时间范围与学科筛选约束。错题统计页签在错因分布右侧还有「难度分布」卡片：按难度星级（1~5 星）展示每个难度的总错题数与已掌握数，已掌握部分以不同颜色叠加显示；未评定的错题也会单独列出。没有任何已评星错题时该卡片不显示。错题统计页签在概览与进度条下方还有「薄弱知识点」排行：按未掌握错题数、近期练习错误率排序，列出最需要巩固的知识点 Top 10，点击一行可跳转到对应错题本并按该知识点筛选的错题列表（地址栏带 `?tag=` 参数）；排行只统计当前时间范围内、当前学科筛选下的错题，近期正确率口径与练习统计一致（近 30 天已作答记录，排除重复导入产生的记录）。练习统计页签顶部还有「学习日历」热力图，以 GitHub 风格方格展示最近 26 周每天的学习活动（录入错题 + 练习次数），并显示当前连续天数、最长连续天数和累计活跃天数；录入错题也算活动，所以没有练习记录时热力图也能显示。练习统计页签最下方还有「反复错题目」榜：列出所选范围内做错 2 次以上的题目 Top 10（含举一反三、试卷、手动录入与重复导入的做错记录），每行显示题干预览、学科、出错次数、最近出错日期和复习状态，点击可跳到对应错题详情，提示重点复习；没有数据时显示一句简短提示。

知识点也在统计中心：「知识点」页签顶部可切换标签体系（导入其他标签体系后显示切换器），按知识点汇总展示使用频率 Top 20（不同标签体系或学科的同名知识点分别计数），下方可浏览各学段学科的标准知识点并添加自定义标签，均按所选体系显示和添加。原 `/tags` 链接会自动跳转到这里。

日期和统计边界使用[应用时区](Settings-and-Users)。更改时区会影响按日或按月分组，但不会平移数据库中的时间。
