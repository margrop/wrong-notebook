# 常见问题

## 默认管理员是什么？升级会重置密码吗？

全新安装的默认管理员为 `admin@localhost`，密码 `123456`，首次登录时必须先修改密码才能使用其他页面。登录页下方的“首次使用？”会给出默认管理员邮箱和本页链接，不显示密码。已有数据库在 `PRESERVE_EXISTING_DATA=true` 下升级时，启动脚本跳过管理员播种，保留账户状态。忘记密码可参考仓库的 [`scripts/reset-password.js`](https://github.com/margrop/wrong-notebook/blob/main/scripts/reset-password.js)，操作前先备份。

## 登录后跳回登录页，或反向代理下登录失败？

检查 `NEXTAUTH_URL` 是否等于浏览器实际使用的完整地址，`NEXTAUTH_SECRET` 是否正确配置且重建容器后保持一致，以及代理是否正确转发访问主机和协议。确认配置生效后重新登录。

## 修改了环境变量，AI 仍然使用旧配置？

网页保存的字段优先于环境变量。先检查“设置 → AI 设置”中的提供商、模型和激活实例。修改容器环境变量后，需要重建容器；网页配置保存后，后续 AI 请求读取新配置。

## 能测试连接，但识别图片失败？

连接成功不代表模型支持图片输入。确认所选模型具备视觉能力，兼容接口接受图片请求，图片完整可读，并检查服务端到服务商的网络。容器中的 `localhost` 指容器自身，详见 [AI 模型配置](AI-Configuration)。

## 提示“AI 返回格式异常”或动画生成失败？

检查模型是否遵循标签或 JSON 输出格式，以及最大输出长度是否足够。动画包含较长 SVG 代码，短输出限制容易导致截断。可切换更适合的模型；遇到超时再检查网络并调整管理员的分析超时设置。

## 动画的语音讲解没有声音或按钮不可用？

默认的语音讲解使用浏览器自带的语音合成，不调用 AI 服务；管理员可在「设置 → AI 设置 → 语音讲解」改用云端语音，云端语音不依赖设备是否装有语音，合成失败时自动改用浏览器语音。喇叭按钮为灰色时，表示当前浏览器没有该语言的语音：Linux 浏览器常缺少中文语音，需在系统中安装；安卓 App 的内置浏览器暂不支持。按钮可用但没有声音时，检查设备音量和静音开关，iPhone 需关闭静音模式。iPhone 和 iPad 的 Safari 只允许在点击后发声：动画自动播放时若没有声音，点一下页面或播放按钮即可开始朗读。

## 屏幕截图按钮不可用？

屏幕截图使用浏览器的 `getDisplayMedia()`，需要 HTTPS 或 `localhost` 安全上下文，还需要浏览器与系统支持并允许屏幕共享。通过局域网 HTTP 地址访问通常不满足要求；配置 HTTPS 后，移动浏览器仍可能不支持，可改用拍照、上传或粘贴图片。

## 公式显示为源码，或者配图有误？

先核对公式定界符、反斜杠和 KaTeX 支持的语法，使用源代码/预览检查；详情页检测到错误时可尝试“修复 LaTeX”。SVG 配图由 AI 生成，仍需对照原图确认几何关系，必要时重新生成。

## 导入后题目数量没增加？

可能命中了相似度判重。查看提示及原题作答历史；重复题会记录为原题的一次做错。默认阈值 90%，相似度严格大于阈值时判重，可在个人设置中调整，详见[错题管理指南](User-Guide)。

## 难度和 A/B 卷为什么不同？

难度与卷别是两个字段。未指定卷别时，1～3 星默认 A 卷、4～5 星默认 B 卷；手动选择的卷别优先保留。修改星级不会要求覆盖已存在的手动卷别。

## AI 分析百分比长时间停住？

百分比是当前阶段的估计值；AI 服务通常不会返回真实完成比例。结合阶段说明、已用时间和后台任务状态判断，超时后查看错误信息，避免连续重复提交相同任务。

## 重启后后台任务列表为什么清空？

任务列表保存在进程内存中，服务重启会清空，运行中的任务不能自动恢复。先检查题目或试卷是否已保存，再决定是否重试；页面上的任务状态不是唯一的数据保存依据。

## HTTP 207 是否表示 Openclaw 导入成功？

`207` 表示批次存在逐项失败；当前实现中全部识别失败也可能返回它。必须读取 `successCount`、`failCount` 和每项 `results`。单张识别超时目前最多 3 秒，更多限制见 [Openclaw 集成](Openclaw-Integration)。

## 导出的 JSON 能恢复整个站点吗？

当前 JSON 不包含完整账户凭据和服务端配置。整站恢复应保存完整数据库、`config/`、部署配置和所需证书，详见[备份与恢复](Backup-and-Restore)。

## 升级后数据不见了，或者容器无法启动？

先核对原有 `data/` 和 `config/` 是否仍挂载到 `/app/data`、`/app/config`，再查看容器日志中的迁移与权限错误。不要删除数据目录来尝试修复；保留现场与备份，按[部署指南](Deployment)检查版本兼容性。

## 如何反馈问题？

在 [GitHub Issues](https://github.com/margrop/wrong-notebook/issues) 中提供运行版本、部署方式、浏览器、复现步骤和脱敏后的日志。版本可从设置“关于”或 `/api/health` 获取；不要提交 API Key、密码、会话信息或完整数据库。
