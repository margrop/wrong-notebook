第三方组件说明：HEIC/HEIF 照片转换
Third-party notice: HEIC/HEIF photo conversion
==================================================

中文
----

本应用在浏览器无法直接解码 HEIC/HEIF 照片时，按需加载 npm 包 heic-to 1.6.6 的
dist/csp/heic-to.js（本项目未修改其源码），由 Next.js 构建时打包为单独的脚本文件，只在需要转换时下载。
该文件包含以下组件，各自的许可证文本位于本目录：

| 组件 | 版本 | 许可证 | 版权与来源 | 本目录中的文件 |
| --- | --- | --- | --- | --- |
| heic-to | 1.6.6 | LGPL-3.0-or-later | Hopper Gee，https://github.com/hoppergee/heic-to | heic-to-LICENSE.txt |
| libheif（编译为 JavaScript/WebAssembly） | 1.23.6（heic-to 1.6.6 说明中标注的版本） | 库部分为 LGPL-3.0 | struktur AG，https://github.com/strukturag/libheif | libheif-1.23.6-COPYING.txt |
| libde265（HEVC 解码，随 libheif 构建） | 1.0.16（heic-to 构建说明中的 LIBDE265_VERSION） | 库部分为 LGPL-3.0 | struktur AG，https://github.com/strukturag/libde265 | libde265-1.0.16-COPYING.txt |
| Emscripten 生成的运行时代码 | 构建所用版本未在产物中标注 | MIT 与 University of Illinois/NCSA 双许可 | Emscripten authors，https://github.com/emscripten-core/emscripten | emscripten-LICENSE.txt |

libheif 与 libde265 的 COPYING 文件中也包含其示例程序适用的 MIT 许可证；本应用分发的是库本身，不含其示例程序。

对应源码与构建说明：
- heic-to 1.6.6 源码（含打包脚本 esbuild.mjs 及 README 中的 libheif 构建说明）：
  https://github.com/hoppergee/heic-to/tree/v1.6.6

  （heic-to 使用该仓库的 build-emscripten.sh，以 LIBDE265_VERSION=1.0.16 USE_UNSAFE_EVAL=0 USE_WASM=0 构建 CSP 版本）

替换方式：本应用以 MIT 许可证开源（https://github.com/margrop/wrong-notebook），
heic-to 作为独立依赖（package.json 中的 "heic-to": "1.6.6"）通过动态 import 加载。
可将其替换为自行修改或重新构建的兼容版本后，按项目文档重新构建应用。

English
-------

When the browser cannot decode a HEIC/HEIF photo itself, this app loads
dist/csp/heic-to.js from the npm package heic-to 1.6.6 on demand (its source is not modified
by this project). Next.js bundles it at build time as a separate script that is downloaded only when a conversion is needed.
That file contains the components below; their license texts are in this directory.

| Component | Version | License | Copyright and source | File in this directory |
| --- | --- | --- | --- | --- |
| heic-to | 1.6.6 | LGPL-3.0-or-later | Hopper Gee, https://github.com/hoppergee/heic-to | heic-to-LICENSE.txt |
| libheif (compiled to JavaScript/WebAssembly) | 1.23.6 (as stated in the heic-to 1.6.6 documentation) | LGPL-3.0 for the library | struktur AG, https://github.com/strukturag/libheif | libheif-1.23.6-COPYING.txt |
| libde265 (HEVC decoding, built with libheif) | 1.0.16 (LIBDE265_VERSION in the heic-to build notes) | LGPL-3.0 for the library | struktur AG, https://github.com/strukturag/libde265 | libde265-1.0.16-COPYING.txt |
| Runtime code generated by Emscripten | Version used for the build is not recorded in the output | Dual MIT and University of Illinois/NCSA | Emscripten authors, https://github.com/emscripten-core/emscripten | emscripten-LICENSE.txt |

LGPL-3.0 supplements GPL-3.0; the full GPL-3.0 text is in GPL-3.0.txt.
The COPYING files of libheif and libde265 also contain the MIT License that applies to
their sample applications; this app distributes the libraries only, not the samples.

Corresponding source and build instructions:
- heic-to 1.6.6 source (including the esbuild.mjs bundling script and the libheif build
  notes in its README): https://github.com/hoppergee/heic-to/tree/v1.6.6
  npm package: https://www.npmjs.com/package/heic-to/v/1.6.6
- libheif 1.23.6: https://github.com/strukturag/libheif/releases/tag/v1.23.6
  (heic-to builds the CSP version with that repository's build-emscripten.sh using
  LIBDE265_VERSION=1.0.16 USE_UNSAFE_EVAL=0 USE_WASM=0)
