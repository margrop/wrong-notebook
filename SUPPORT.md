## 提问与反馈 / Questions and bug reports

在 [Issues](https://github.com/margrop/wrong-notebook/issues) 中先搜索是否已有相同问题，再按模板提交。请写明运行版本（「设置 → 关于」或 `/api/health`）、部署方式、AI 提供商与模型、复现步骤和脱敏后的日志。

Search the [issues](https://github.com/margrop/wrong-notebook/issues) first, then use the templates. Include the running version (Settings → About or `/api/health`), deployment method, AI provider and model, steps to reproduce and redacted logs.

不要在公开内容中附上 API Key、密码、会话信息或完整数据库。Never post API keys, passwords, session data or a full database publicly.
